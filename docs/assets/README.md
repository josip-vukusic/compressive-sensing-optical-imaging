# Original research assets

[← Project overview](../../README.md)

These figures and documents come from the author's **Diplomski Rad** archive. The table records paths relative to that original folder. All listed source files were copied byte for byte: no cropping, retouching, recoloring, rescaling, or changes to axes, data, captions, or PDF pages. GitHub scales images for display; clicking an image opens the original asset.

The complete thesis is taken from `Diplomski rad Vukusic 2017/diplomski-vukusic.pdf`. The PDF with the same name at the archive's top level is an earlier draft and is not included.
